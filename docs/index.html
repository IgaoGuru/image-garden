Image Garden

Image Garden is a software toy for exploring your photo library as a 3D embedding map.

Drop in a folder. Image Garden embeds your images locally, arranges them by visual meaning, and lets you fly through the result.

for rendering / ML nerds

The viewer uses WebGL instancing, texture pages, frustum culling, screen-size LOD, world scaling, and deterministic jitter to keep large photo maps navigable.

The map is built from image embeddings, projected into 3D with UMAP, then tuned so dense clusters remain readable without losing the feeling of an embedding space.

Embeddings run locally with ONNX by default. Image Garden currently defaults to MobileCLIP-S1, with OpenCLIP/PyTorch-style paths kept for experimentation.

The runtime is intentionally boring: a local backend, generated thumbnails, cached embeddings, and a browser viewer. No cloud photo upload is required.
